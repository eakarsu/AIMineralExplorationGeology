# Operator runbook

Install explicitly, review migrations, and run `DATABASE_URL=... ./scripts/migrate.sh`; `./start.sh` only starts already-prepared child processes and refuses occupied ports. Configure a non-placeholder 32+ character JWT secret and keep experimental/provider routes quarantined.

Targets require versioned geology evidence, sample custody, permits, environmental/consultation references, independent technical approval, and contractor receipts. External LIMS, claim registry, drilling, geophysical, drone, or hardware execution is blocked without credentials and contract evidence. A qualified geologist retains final responsibility; on provider failure, preserve custody/audit data, mark the program failed, and use the documented manual recovery plan.
